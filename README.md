# C++ zombie western terminal

## Overview

This repository contains a text-based game set in the wild west, made to practise the basics of C++. You can find more about Modern C++ on the [Learn C++ website](https://learncpp.com/).

> *Note: The game project includes personal debugging comments (`// ...`). I use these annotations as notes to remind myself of the difficulties I ran into and to track the mistakes I made.*

## Features

- **Development Environment:** Visual Studio 2026

## Getting Started

To get started with this project, follow the instructions below:

### Recommended Prerequisites

- **Visual Studio 2026**: Install Visual Studio 2026 or up with the required components for C++ desktop development.

### Clone the Repository

1. Clone this repository to your local machine using Git:

   ```bash
   git clone https://github.com/diotchristopher/cpp-zombie-western-terminal.git
   ```
